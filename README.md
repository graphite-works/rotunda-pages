# rotunda-pages

This repository is a generated mirror of the Rotunda project's
`docs/privacy-policy.md` and `docs/store-listing-draft.md` (from the main
`gov-info-finder` repository), published here as static HTML so App Store
Connect and Google Play Console have a real, publicly-reachable privacy
policy URL and support URL in their metadata fields.

It is maintained by the Rotunda project.

- `index.html` — the public Privacy Policy page, adapted from
  `docs/privacy-policy.md`.
- `support.html` — the public Support page, adapted from the support-URL
  requirements described in `docs/store-listing-draft.md`.

**Future policy updates should originate in `docs/privacy-policy.md`** in the
main repository, then be re-mirrored here. Do not edit the content of this
repository independently of that source document.
